# podor 0.4.0

这次更新重新整理绘画工作台，完善笔刷，图层与动画操作，并更换应用图标。

## 工作台

- 当前工具的快捷操作集中在画布下方悬浮胶囊，支持画笔，橡皮，柳叶笔，选区，渐变和漫画线。
- 参数弹窗采用圆润胶囊，柔和阴影与展开动效，移除弹出时的直角阴影和开关光圈，选中按钮使用圆形背景。
- 面板入口再次点击即可收起；视图，剪贴板和参考图入口移到侧边工具栏，移除视图面板与底部状态栏。
- 调整设置直接在侧栏展开，填充设置固定底部。切换工具或开始绘画退出未确认预览，撤销与重做快捷键恢复正常操作。
- 完全移除启动动画，直接按已保存主题和启动页进入程序。

## 绘画与图层

- 24 个内置笔刷覆盖线稿，纸纹，水彩，油彩与像素绘画，支持材质与压感参数，自定义预设，搜索与收藏。
- 柳叶笔用于闭合轮廓填色或擦除；柳条笔跟随运笔方向，表现叶形笔尖与起收笔变化。
- 支持涂抹混色，对称绘画，渐变，色卡交换，选区细化，透视辅助，集中线与速度线。
- 图层提供分组，剪贴，多个蒙版，调整图层和基本矢量节点编辑。蒙版缩略图保持方形，设置改为独立窗口。
- 桌面画布使用品牌图标中的原生笔形鼠标指针，笔尖对应落笔位置，移除额外黑圈。

## 动画与文件

- 打开动画面板即可初始化时间轴，增加复制与删除帧快捷按钮，重整间距与完整画面缩略图。
- 帧标尺与图层轨道固定在面板底部，支持横向拖动，关键帧与连续共享单元显示。
- 支持帧时长，播放方向，范围，帧标签和洋葱皮，输出 GIF 与 PNG 图集。
- 工程保存为 `.pod`。Aseprite 与 SVG 导出入口使用对应项目的官方标志，其他格式明确显示文件类型。
- 更新 README 封面与十分钟音乐演示《让创作更顺手》，使用浅色英文界面与中文字幕，不含配音，另提供可选英文字幕。展示笔刷用法，花卉厚涂练习与 Kotlin / Compose / Rust 实现。
- 附带花卉练习的五个阶段工程与画布 PNG，可打开继续绘画。

## 构建与发布

- 版本统一为 0.4.0，Android 与 iOS 构建版本从同一版本目录派生。
- GitHub 分别构建 Windows MSI，macOS DMG，Linux DEB，Android Debug APK 与 iOS 模拟器应用及未签名设备归档。
- 修复 Android 共用资源打包与 iOS 共用 Skia 源集和 Rust 静态库连接。

移动端与其他桌面平台仍需设备验收。macOS 未签名且未 notarize，Android 使用开发签名，iOS 设备归档需 Apple 签名后才能安装。PSD，ORA，Aseprite 与 SVG 交换仅覆盖当前实现的能力，不能视为完整格式兼容。
