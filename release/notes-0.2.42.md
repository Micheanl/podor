## 数位板与按钮

- 新增 WinTab 通道，自动读取设备压感范围和笔尖按键映射，支持笔尾橡皮擦。
- 设置可切换自动、Windows Ink 和 WinTab；WinTab 驱动不可用时回退 Windows Ink。
- 支持悬停笔刷光标，按住笔侧键落笔取色。
- 修正轻压采样，保留停笔时的压力变化，避免按键切换被输入合并吞掉。
- 增加失焦、离开感应范围和采样溢出时的笔画取消处理。
- 主要按钮和选中工具改用渐变描边、深色内芯，悬停与按下时渐变沿边框转动，空闲时停止动画。

沿用 0.2.41 的曲线调色、直方图和画布参考图。参考图不进入最终导出。

已完成模拟输入与 Windows 原生输入测试，Wacom 各型号仍需实机验证；倾斜、旋转和触控环未作为原生功能接入。ExpressKeys 可在 Wacom 驱动中绑定 Podor 快捷键。
