# podor 0.3.1

这次更新补齐了笔刷的起收笔手感和几支常用画笔。

## 绘画

- 新增 6 支内置笔刷，共 22 支：柳叶笔、柳条笔、混合笔、油彩笔、纸纹笔、水彩纸。
- 柳叶笔尖随笔画方向旋转，起笔从针尖渐渐胀开、收笔自然收尖，接近现代绘画软件的锥形笔触。
- 修复方向类笔尖（柳叶、缎带、排线等）起笔时出现横向小痕的问题：笔画方向未稳定前按圆头落笔，点按也是干净的圆点。
- 排线笔重做为排齿笔尖，一次画出四条平行线，沿笔画连续不断线。
- 新增纸纹滑杆：纹理按画布坐标平铺，多笔之间保持同一张纸，适合铅笔、水彩和干扫质感。
- 新增调色混合滑杆：选中即切换为涂抹工具，涂抹时把当前笔刷颜色按比例掺入笔触，用于混色衔接。
- 稳笔在平滑路径的同时平滑压感，快速运笔时粗细抖动明显减小。
- 笔刷库预览重绘：柳叶显示锥形笔触、排齿显示四条细线、纸纹与颗粒显示纹理点。

## 笔刷包

- 插件格式新增 `tip: Leaf / Comb`、`paper`、`mix` 字段，旧笔刷包不受影响。

本次提供 Windows x64 MSI。安装包同时发布到 Gitee 和 GitHub，应用内更新通道同步验证。
