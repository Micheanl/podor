# podor 0.3.2

这次更新对照 GIMP、MyPaint 等开源绘画软件的笔刷引擎，重做了笔触质量与收锋手感，并补上自定义笔刷的删除。

## 绘画

- 笔触边缘加入超采样抗锯齿：所有笔尖的轮廓按像素四点采样，画圆、画圈的边缘不再有锯齿台阶，细线也更顺滑。
- 柳叶笔收笔重做：抬笔时沿笔画末段方向甩出一段渐细的收锋，起笔从针尖渐渐胀开，接近现代绘画软件的锥形笔触。
- 修复收锋方向计算反了的问题：上一版收锋会向笔画侧面甩出。
- 修复方向类笔尖（柳叶、缎带、排线、排齿）起笔出现孤立圆点的问题：笔画方向未稳定前落笔按锥度收细，起笔是干净的尖点。
- 排齿、缎带等方向类笔尖在急转弯处不再以全尺寸圆点收尾。
- 柳叶笔笔尖比例收紧到 0.35，笔锋更锐利。

## 笔刷管理

- 自定义笔刷支持删除：编辑笔刷中点击垃圾桶，再次点击确认；删除后同步清理收藏，当前选中时回到墨水笔。

本次提供 Windows x64 MSI。安装包同时发布到 Gitee 和 GitHub，应用内更新通道同步验证。
