# podor 0.3.0

这次更新重新整理了绘图界面，也补上了日常绘画中常用的操作。

## 界面与主题

- 新增浅色主题，在设置中点击太阳、月亮图标即可切换，重启后保留选择。主页、工具面板、弹窗和窗口边框同步适配。
- 工程、剪贴板和常用工具菜单改为紧凑图标，悬停可查看名称与快捷键，移除重复的底部说明。
- 普通滑块统一跟随当前绘画颜色；色相、饱和度、明度保留渐变。滑钮改用细环样式，支持长按数值后拖动微调。
- 搜索和收藏入口去掉圆形底色，手指绘画开关去掉按压光晕。新建画布中的纸张预览保持白色。
- 菜单与弹出控件加入细线环绕效果，浅色模式使用深色线条，播放完成后停止重绘。
- 窗口按钮并入顶部工具栏，保留拖拽、缩放和最大化操作；作品列表改为完整图片轮播。
- 更新开屏效果与图标溶解过渡，标题栏与启动页保持一致。

## 绘图操作

- 左侧画笔、橡皮和涂抹工具支持长按或右键展开独立滑块，再次点击当前工具也可展开或收起；右侧面板默认收起。
- 在画布上右键可快速调整工具，右键操作不会绘制笔画。
- 增加放大、缩小与画笔尺寸快捷键：Ctrl/⌘ + 加号、减号调整视图，[ 和 ] 调整笔刷大小，可在设置中重新绑定。
- 选区建立后可直接拖动所选像素，移动完成后清除选区，一次拖动可一步撤销。
- 图层名称支持长按拖拽排序，靠近列表边缘自动滚动，拖动时显示位置提示。

## 修复与安装

- 修复部分 Windows 启动时只显示透明边框的问题。
- 启动前先读取保存的主题，修复浅色模式开屏第一帧闪出深色的问题。
- Windows 安装包使用系统自带的 UCRT，避免重复写入 runtime/bin/ucrtbase.dll。
- 保留桌面快捷方式和应用内更新，更新流程禁止自动重启电脑，完成后重新打开程序。

本次提供 Windows x64 MSI。Android 共享界面已通过编译，未提供移动端安装包。Windows 10 首次安装与不同 Wacom 型号仍需实机验证。
