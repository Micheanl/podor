podor 是一款绘画与图像编辑软件。Rust 处理笔触与像素，Kotlin 管理状态和任务，Compose Multiplatform 构建共用界面。

0.4.0 重新整理工作台。常用工具留在侧栏，当前工具的快捷参数出现在画布下方的悬浮胶囊中。面板入口再次点击即可收起，画布不再显示底部状态栏。程序读取偏好并初始化引擎后直接进入首页或画布，启动动画已完全移除。

### 绘画与颜色

24 个内置笔刷覆盖线稿，铅笔，马克笔，水彩，油彩和像素绘画。提供笔尖形状与角度，间距，硬度，颗粒，纸纹，稳笔和压感曲线调整，像素笔触采用对应模式的规则。笔刷库支持搜索，收藏，来源筛选和自定义预设保存，也可导入笔刷包。

柳叶笔沿闭合轮廓填色或擦除，适合构建剪影与花瓣色块。柳条笔使用随笔画方向旋转的叶形笔尖，表现起笔与收尖。涂抹沿笔触推动已有颜色，可加入笔刷颜色混合。画笔和橡皮支持左右，上下与双轴对称，一笔记一次撤销。

色轮与滑块用于取色，个人色卡可保存颜色并从画布提取主色。色卡支持 Adobe ASE，GPL 与 JASC PAL 导入导出。线性和径向渐变可调整两端颜色，反转方向或淡出到透明；区域填充支持容差与取样设置。

### 选区与图层

矩形，椭圆，套索与魔棒选区可添加，相减，相交或反选，并支持扩展，收缩，平滑和羽化。复制或剪切选区，粘贴图片为新图层，拖动缩略图排序，也可移动，变换，复制与合并图层。

图层支持八种混合模式，内容锁定，透明度锁定，剪贴与嵌套分组。多个蒙版可启停，链接，反相，复制与排序。蒙版保留方形缩略图，设置在独立窗口中编辑。明暗色彩，曲线与渐变映射还可建立调整图层。

调整侧栏直接展开画布大小，图像尺寸，明暗色彩，模糊，曲线与渐变映射，填充设置固定在底部。预览可对比原图，重置，确认或取消；开始绘画或切换工具会退出未确认预览，撤销与重做快捷键保持可用。

### 辅助与像素

平行，径向与一至三点透视助手辅助构图；集中线与速度线在画布上预览，常用参数位于悬浮胶囊。基础矢量工具支持矩形，椭圆，直线，路径与节点编辑，并可输出 SVG。像素铅笔，像素完美笔刷，像素网格与最近邻缩放用于像素绘画，索引色文档可编辑调色板并输出索引 PNG。

缩放，平移，旋转和镜像只改变视图，不改作品像素。视图控制，剪贴板和参考图入口位于侧边工具栏。参考图可移动，缩放，镜像与隐藏，不参与导出；切换作品或退出后清除。

### 逐帧动画

打开动画面板即可开始。快捷操作包含播放，洋葱皮，添加，复制与删除帧。完整画面缩略图用于选帧，帧标尺与图层轨道固定在面板底部，支持横向拖动，显示关键帧和连续共享单元。可设置帧时长，播放方向，范围与帧标签，并导出 GIF 或 PNG 图集 ZIP。

### 文件与工作台

工程保存为 `.pod`，旧 `.podor` 文件仍可读取。PNG，JPEG 与静态 WebP 支持导入导出，TIFF 与 BMP 支持导出。PSD，ORA 与 Aseprite 提供受限的分层交换；复杂内容可显式烘焙。外部格式无法保留全部图层结构和效果，SVG 也仅支持当前工具实现的子集。

浅色与深色主题，中文与英文界面，界面缩放，快捷键和工具栏均可调整。工具栏可停靠四边，调整顺序或隐藏工具；侧面板可切换左右。鼠标进入桌面画布时使用品牌图标中的笔形指针，热点位于笔尖，不再附加黑色圆圈。

作品首页提供缩略图，搜索与排序。作品需要手动保存，切换作品或退出前会提示未保存的改动。

### 下载与平台

| 平台 | Release 产物 | 当前范围 |
| --- | --- | --- |
| Windows x64 | MSI | 桌面安装包，支持应用内更新 |
| macOS ARM64 | DMG | 未签名，未 notarize，需设备验收 |
| Linux x64 | DEB | 需桌面环境验收 |
| Android ARM64 / x64 | Debug APK | 开发签名，需设备验收 |
| iOS ARM64 | 模拟器应用，未签名归档与静态框架 ZIP | 设备安装需要 Apple 签名与配置 |

多平台由 [GitHub Actions](https://github.com/Micheanl/podor/actions) 分别编译与打包，具体产物以对应 Release 为准。离屏渲染测试不等于实体设备验收。

Windows MSI 按提示安装。设置中可以检查并安装更新，下载后校验大小和 SHA-256。安装前提醒未保存作品，不自动重启电脑。WinTab / Windows Ink 支持压感，笔尾橡皮擦与侧键取色；各型号仍需实机验证，倾斜与触控环暂未接入。

### 从源码运行

准备 JDK 25 或更新版本，Rust 和平台 C++ 工具链：

```powershell
./gradlew.bat :desktopApp:run
```

macOS 与 Linux 使用 `./gradlew`。版本集中在 `gradle/libs.versions.toml`。构建，测试和发布见[开发说明](docs/DEVELOPMENT.md)，笔刷扩展见[格式说明](docs/PLUGINS.md)。

像素按块更新，历史共享未修改的像素块。光栅化与文件读写在后台执行；Compose / Skia 负责界面与画面合成，绘画引擎的像素计算在 CPU 上执行。
